# Decisions

One line each. Newest at the bottom.

- 2026-10-30 Backend: Next.js API routes on Vercel instead of Convex for tonight (no Convex deployment configured; user approved). Pipeline code in `lib/pipeline.ts` is framework-agnostic so it can move into Convex actions later.
- 2026-10-30 Streaming without Convex: the browser asks `/api/story`, then `/api/scene` for every scene in parallel (scene 0 first); page 1 plays as soon as scene 0 returns. Routes are stateless (the bible travels with each scene request).
- 2026-10-30 Jev is called directly on the TypeSafe API (`POST https://api.typesafe.ai/v1/systemone`, `JEV_API_KEY`), no Vercel AI Gateway (user instruction). Pinned `JEV_MODEL=jev-1.14.0`; a `typesafe-ai/` prefix is stripped.
- 2026-10-30 No live provider calls were made during the build (user instruction). Every provider falls back automatically to a deterministic mock / draft path when its key is missing, so the app runs end to end with zero keys.
- 2026-10-30 Timeline layout: each page = 1.6 s lead (backdrop draws, `PAGE N` written) + the scene's audio + 1.2 s tail; the last 0.6 s is a page-turn wipe; `THE END` holds 3.4 s.
- 2026-10-30 Lights semantics: a `lights` action flips the user's chosen base theme relative to the story's `startLights`, so every lights change is visible whichever theme the user picked.
- 2026-10-30 Characters stand on the ground line; `Pos[1]` is ignored for characters (kept for props). Character height = min(32% of board height, 30% of width) x skin.scale.
- 2026-10-30 Path flattening is pure TypeScript (own M/L/C/Q/Z sampler) instead of `SVGPathElement`, so lint and tests run in Node.
- 2026-10-30 `INK_MODE=chalk` is not implemented; it falls back to mono (UI and board are black and white only).
- 2026-10-30 Lint auto-corrections (unknown ids dropped, auto-enter for characters that act or speak before entering, later move wins on conflicts) are logged as WARN so tests catch them.
- 2026-10-30 Golden story ("Ember and the Dark") is hand-written in `data/golden/source.ts`; `pnpm golden` bakes `data/golden/story.json` with draft-voice timings; the app bundles it so it plays offline.
- 2026-10-30 TypeScript pinned to 5.x (TS 7 was installed by default; Next 16 type-checks with TS 5).
- 2026-10-30 Deployed to Vercel project `fablecast` (https://fablecast.vercel.app). `vercel.json` pins the Next.js framework (the CLI-created project defaulted to "Other"). `.vercelignore` keeps `.env*` and `.cache` out of the upload; provider keys live only in Vercel's encrypted env vars (marked sensitive). MOCK_* = 0 and VOICE_PROVIDER=eleven in production.
- 2026-10-30 Daily spend caps and session counters are in memory per server instance on Vercel, so they are approximate across instances; the ElevenLabs cap (4,000 chars/day) is the main guard on credits.
- 2026-10-30 Backend moved to Convex (user request), superseding the first line above. Convex project `fablecast`: dev deployment `coordinated-heron-779` (forced to mock: MOCK_*=1, VOICE_PROVIDER=draft, no keys) and production `stoic-warthog-806` (live keys and settings). Vercel only serves the Next.js app and reads `NEXT_PUBLIC_CONVEX_URL`.
- 2026-10-30 Convex flow: `stories.create` mutation (session limit by a per-browser id in localStorage) -> `pipeline.generateStory` action -> one `scenes` row per page -> `pipeline.processScene` actions (scene 0 first, one retry). The player subscribes to `stories.get`; scene audio is in Convex file storage and served by URL.
- 2026-10-30 The content-addressed cache and the daily spend caps are durable in Convex (`cache`, `usage` tables); `lib/cache.ts` binds a per-call backend with AsyncLocalStorage so concurrent actions never share one. lib/pipeline.ts is unchanged and still powers the API-route fallback when no Convex URL is set.
- 2026-10-30 Convex functions are deployed from this machine (`npx convex deploy`), not from the Vercel build, so no Convex deploy key is stored in Vercel.
- 2026-10-30 Provider keys removed from Vercel (user approved); they live only in Convex production. The leftover Vercel /api routes now run mock/draft only, so they cannot spend credits.
- 2026-10-30 Raised MAX_DAILY_ELEVEN_CHARS to 10000 on Convex production (user request); about 7 fully voiced stories a day. .env still says 4000 for local runs.
- 2026-10-30 Six fully voiced stories a day (user request): DAILY_STORY_RUNS=6 with MAX_DAILY_ELEVEN_CHARS=10000, so each story is sized to 1,666 voice characters (text + 30 reserved per line for audio tags). The Story Director's word budget and the trimmer both enforce it (prompt version story-v2). Convex counts a run in stories.create, transactionally, and refuses the 7th; the day is the UTC date (it turns over at 5pm in San Francisco). Home shows the live count.
- 2026-10-30 Claude fixes after the first live run: tool schemas are converted to JSON Schema 2020-12 (tuples -> fixed-length arrays) and calls use tool_choice auto + a firm instruction, since claude-sonnet-5-5 rejects forced tool_choice; effort low, max_tokens >= 16000 (thinking counts toward it).
- 2026-10-30 ElevenLabs only (user request): no browser speech and no draft fallback in live mode. 429 concurrent-limit responses are waited out (up to 150 s per request, jittered backoff); requests within a page run one at a time; a page that still fails is retried by Convex (up to 4 attempts). Draft timing remains for dev/mock only.
- 2026-10-30 Live playback (user request): no seeking, restart or future lines until the story ends; the clock holds while a page's audio loads, so sketches follow the voice.
- 2026-10-30 Limits (user request): no daily token or character caps (MAX_DAILY_*=0); 6 stories a day; MAX_STORY_SECONDS=120 now caps the whole video (speech + 2.8 s per page + 3.4 s THE END); WORDS_PER_SECOND=2.35 measured from real v3 takes.
- 2026-10-30 Tones (user request): COZY, SILLY, ADVENTURE, A LITTLE SPOOKY, DREAMY on Home (lib/tones.ts), stored per browser and sent with the story. The tone steers the Story Director and the voice: Claude now writes a `performed` version of every line with 1-3 inline ElevenLabs v3 audio tags where the feeling changes, timing punctuation and one CAPS word. It is used only if it speaks exactly the caption's words (so captions stay in sync); otherwise the line falls back to Jev's mood tags. eleven_v3 stability: 0 (creative, most expressive) for every tone except DREAMY (0.5); the whole page shares it, so a calm first line no longer flattens the page. Story cache key includes the tone (prompt v4).
- 2026-10-30 Natural pace (user feedback "slow"): the last live story read at 1.3-1.9 words/s because every page carried 3 pause tags plus ellipses. The live pipeline no longer adds or keeps pause tags; Claude paces each acted line to the moment (quick for action, slow only for calm/sleepy). WORDS_PER_SECOND=2.1 for the length budget.
- 2026-10-30 Faster pages: ElevenLabs voicing now starts as soon as Jev has routed the page, in parallel with Stage Director staging (it never needed the staging).
- 2026-10-30 Voices by character (VOICE_MODE=cast, new default): the narrator (Claude picks female/male) reads narration; each character gets a pool voice matching its gender and age and speaks its own dialogue (`speaker` per line). Jev's performer choice still drives mood tags, ink and expression.
- 2026-10-30 Story-specific sketches (staging-v2): backdrop must match each page's place (no default night_forest), 4-8 props with at least 2 custom-drawn ones for the story's own objects, all tappable with fitting reactions, 2-3 actions per line. Story Director (story-v5) must keep the premise's specifics so different premises look and sound different.
- 2026-10-30 Home: BEDTIME STORIES title in Geist Pixel with a stepped, letter-by-letter bounce (off under prefers-reduced-motion).
- 2026-10-30 End-only rewind (user request): during the live telling only play/pause shows; the end row offers REWIND (renamed from AGAIN) and NEW STORY, and the transport's rewind unlocks after the end.

The face Claude picks overrides Jev's; Jev still picks performer, intensity, pause and emphasis.
